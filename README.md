# LLM Translator Extension

A browser extension that provides language translation capabilities using AI models.

## Features
- Real-time text translation between 100+ languages
- Support for both web and mobile content
- Customizable translation settings
- Integration with popular browsers

## Installation
1. Clone this repository
2. Open Chrome/Edge and go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this directory

## Usage
1. Click the extension icon in your browser toolbar
2. Select the source and target languages
3. Highlight text to translate or use the context menu option
